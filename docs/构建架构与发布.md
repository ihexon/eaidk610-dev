# EAIDK610 构建架构与发布结论

## 当前架构

- 官方 `armbian/build` 以 Git submodule 固定；本仓库不修改 submodule。
- board、kernel patch、U-Boot 入口、overlay 和镜像定制全部位于
  `userpatches/`。
- 唯一活动构建是 GitHub 托管 ARM64 runner 上的一次标准
  `compile.sh build` 完整镜像构建。
- Armbian 的 ARM64 Docker 环境和 artifact cache 属于标准构建流程。

## 固定组成

| 组件 | 当前选择 |
| --- | --- |
| Armbian | 由 submodule gitlink 锁定 |
| Kernel | rockchip64 edge，Linux 7.2 stable head，加 FUSB302 和 RT5651 无中断修复 |
| U-Boot | upstream `v2026.10-rc3`，EAIDK610 defconfig，binman |
| 启动固件 | mainline TPL/SPL，Rockchip BL31 v1.36 |
| 用户空间 | Debian Trixie Minimal |
| Device tree | upstream EAIDK610 DTB 加单一项目 overlay |

## 发布结论

- 成功产物为 `eaidk610-armbian-edge.img.xz`、image/DTB/headers/libc-dev
  四个内核 DEB、`eaidk610-board-overlays.deb`、`SHA256SUMS` 和
  `BUILD-MANIFEST.txt`。
- 板级 DTBO 由 `eaidk610-board-overlays` 包拥有，安装时默认启用。
- board 包包含正确的 `micbias1` 音频路由、串口 `stdout-path` 和蓝牙固件别名；
  蓝牙固件本体来自 `armbian-firmware`。
- 版本与源码指纹只进入构建清单，不进入面向用户的文件名。
- 失败任务只保留日志和 Armbian 诊断一天，不保存失败镜像。
- 镜像和内核 DEB 来自同一次 Armbian 构建，不维护或重复编译第二套内核。

## 验证状态

- GitHub Actions run `34084367401` 已成功发布 `eaidk610-armbian-edge-r4`，
  包含完整镜像、四个内核 DEB 和 board overlay DEB。
- board 包 `1.0.1` 已在 `.177` 的 Linux 7.2.3 上重启验证：RT5651 声卡注册、
  earlycon 初始化和蓝牙固件 build 0230 加载均成功。
- RT5651 跳过未连接中断的驱动补丁已通过源码应用检查，待新内核构建与实机验证。
- Linux 7.1 kernel-only r1 已在 `.166` 验证 FUSB302 自动 Try.Source、反向
  Source/Host 和 USB2 480 Mbps 枚举。
- Linux 7.2 镜像上的 USB3 双方向、耳机检测和扬声器播放尚未实机验证。
